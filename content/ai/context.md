### myHumana Platform — Healthcare Web and Mobile
Works on the myHumana platform — a Medicare and Medicaid application serving millions

and API layers. Led the implementation of an AI-based search feature from proof of
concept to production.

### Billing Platform — Healthcare Payments
Worked on a billing application enabling Medicare and Medicaid members to make premium
payments securely through the platform. Focused on reliability and security for a
payment-critical user experience.

### Internal Database and Server Hosting Tool
Built an internal tool that allowed engineering teams to provision and host their own
databases and servers on the platform. Focused on internal developer tooling and
platform infrastructure.

### AI-MC Chatbot and Portfolio — Personal Project
Built this portfolio and the AI chatbot powering it as his first self-hosted project.
The chatbot uses a RAG pipeline — chunking, embedding, and vector retrieval — to answer
questions grounded strictly in his resume and this context document. The portfolio is
self-hosted on a Raspberry Pi 5 using Docker Compose, Astro, and FastAPI.
