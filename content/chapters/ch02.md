# Every Tool Earned in Battle

Not a list of technologies skimmed from a tutorial.
These are the things used on real projects, under real pressure,
with real consequences when something broke.

---

## Frontend

Angular has been the longest relationship — deep knowledge of RxJS, NgRx,
component architecture, and performance optimization at scale.
React and Vue followed. Each has its place. The common thread is knowing
not just how to use a framework but how to build something maintainable with it.

TypeScript, Webpack, Storybook, WCAG accessibility compliance —
the details that separate a working application from a good one.

---

## Backend and APIs

ASP.NET Core for high-volume microservices. Python for automation, data tooling,
and increasingly AI work. Node.js where it fits. GraphQL as an orchestration
layer — and the experience of optimizing it when it becomes the bottleneck.

---

## Cloud and DevOps

Azure is home territory. GCP from a major consulting engagement.
Docker, Kubernetes, CI/CD pipelines — not just configured once
but maintained and improved over time.

---

## AI and Data

LangChain, RAG pipelines, OpenAI API, Pinecone.
This is the current frontier — learning by building, not just reading about it.
